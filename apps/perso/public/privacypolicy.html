Politique de confidentialité

PROTOCOLE est une application personnelle à usage strictement individuel, sans compte ni serveur : toutes les données restent stockées localement sur l'appareil de l'utilisateur.

Données de santé (Health Connect)

Avec l'autorisation explicite de l'utilisateur, l'application lit les données de pas et de sommeil via Health Connect (Android), uniquement pour les afficher et les combiner avec les données saisies manuellement dans l'application. Ces données ne sont jamais transmises à un serveur tiers, ni partagées avec quiconque, ni utilisées à des fins publicitaires.
