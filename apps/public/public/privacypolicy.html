Politique de confidentialité

RawCare est un projet personnel — un carnet de suivi musculation, nutrition et récupération, développé et opéré par Yoann, à titre individuel (pas de société, pas d'activité commerciale). Cette page explique quelles données sont collectées quand vous utilisez l'application, pourquoi, et comment les faire supprimer.

Contact pour toute question ou demande sur vos données :
yoann.rolland@gmail.com

Qui a accès à l'application

RawCare est en bêta fermée : les comptes sont créés à la main par Yoann, il n'y a pas d'inscription libre. Si vous avez un compte, c'est que vous avez été invité·e directement.

Données collectées

Selon ce que vous choisissez de renseigner dans l'application :

  • Compte : votre adresse email (gérée par le service d'authentification Supabase).
  • Données de suivi sportif : poids, sommeil, pas, séances d'entraînement (types, séries, charges), escalade.
  • Données de santé (catégorie particulière au sens du RGPD) : les zones de douleur/gêne que vous choisissez de suivre (le cas échéant), avec vos relevés associés.
  • Nutrition : repas et macronutriments que vous enregistrez.
  • Préférences : sports pratiqués, cibles nutritionnelles, échelle d'escalade choisie.
  • Clé API Anthropic (optionnel) : si vous l'ajoutez pour utiliser le Coach IA — voir plus bas.

Tout est saisi manuellement par vous. RawCare ne lit aucune donnée depuis d'autres applications ou capteurs.

Pourquoi ces données sont collectées

Uniquement pour faire fonctionner l'application : afficher votre historique, calculer vos tendances, et — si vous le souhaitez — générer une analyse via le Coach IA. Ces données ne sont jamais revendues, partagées à des fins publicitaires, ni utilisées pour du profilage commercial. Aucun outil d'analyse d'audience tiers (Google Analytics ou équivalent) n'est intégré à l'application.

Où et comment vos données sont stockées

Les données sont hébergées chez Supabase (base de données PostgreSQL managée), sur des serveurs situés dans l'Union européenne. L'accès est protégé par des règles de sécurité au niveau des lignes (Row Level Security) : chaque compte ne peut techniquement lire ou écrire que ses propres données, jamais celles d'un autre utilisateur.

Coach IA — partage avec Anthropic

Le Coach IA est une fonctionnalité entièrement optionnelle. Elle ne s'active que si vous ajoutez votre propre clé API Anthropic dans l'application.

  • Si vous l'utilisez, les données affichées au moment de l'analyse (poids, macros, séances, douleurs suivies récentes, etc.) sont envoyées directement depuis votre navigateur vers l'API d'Anthropic — jamais via un serveur intermédiaire de RawCare, qui n'y a donc pas accès.
  • Cet envoi se fait sous votre propre compte et votre propre clé API Anthropic : c'est votre relation contractuelle avec Anthropic qui s'applique à ces données, pas celle de RawCare. Voir la politique de confidentialité d'Anthropic.
  • Le Coach IA ne remplace pas un avis médical ou un kinésithérapeute — voir le rappel affiché dans l'application.
  • Sans clé API ajoutée, aucune donnée n'est jamais envoyée à Anthropic : l'application fonctionne entièrement sans cette fonctionnalité.

Combien de temps vos données sont conservées

Tant que votre compte existe. RawCare étant en bêta fermée, un compte reste actif tant que vous ne demandez pas sa suppression.

Vos droits

Conformément au RGPD, vous pouvez demander à tout moment, par email à l'adresse ci-dessus :

  • l'accès à l'ensemble de vos données ;
  • la rectification d'une donnée inexacte (possible aussi directement dans l'application pour la plupart des champs) ;
  • l'effacement de votre compte et de toutes vos données ;
  • la portabilité de vos données dans un format exploitable.

À ce stade de la bêta, ces demandes sont traitées manuellement par Yoann (pas encore de bouton "supprimer mon compte" en libre-service dans l'application) — traitées dans les meilleurs délais, sous 30 jours au maximum.

Cookies et stockage local

L'application utilise le stockage local de votre navigateur uniquement à des fins techniques (maintenir votre session connectée). Aucun cookie publicitaire, aucun traceur tiers.

Mineurs

RawCare n'est pas destinée aux personnes de moins de 16 ans.

Modifications de cette politique

Cette page peut évoluer avec l'application. La date de dernière mise à jour figure en haut de page.
